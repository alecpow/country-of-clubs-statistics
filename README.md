## Overview

This release contains aggregate statistics derived from the Country of Clubs research database. It summarizes directory coverage, publishing status, access types, membership-price coverage, compatible cost benchmarks, golf-course scale, and founding-year context.

It does **not** contain club-level records, individual source URLs, unpublished values, or the underlying research database.

## Files

- `country-of-clubs-aggregate-statistics-2026-08-28.csv` — machine-readable statistics, with one metric per row.
- `country-of-clubs-aggregate-statistics-2026-08-28.xlsx` — formatted workbook containing the same statistics, metadata, and data dictionary.
- `report.txt` — human-readable report generated from the aggregate snapshot.
- `METHODOLOGY.md` — scope, calculation, missing-data, and interpretation rules.
- `DATA_DICTIONARY.csv` — definitions for every field in the statistics CSV.
- `FIGSHARE_METADATA.md` — suggested Figshare metadata and a publication checklist.
- `CITATION.txt` — suggested citation text with a DOI placeholder.
- `MANIFEST-SHA256.txt` — checksums for integrity verification.

## Important interpretation notes

- Every percentage uses the stated researched sample or denominator.
- An empty or unresearched field is not treated as a negative response.
- Price benchmarks are based on compatible, recent evidence rather than every club in the market.
- Counts and eligibility decisions describe the database at the snapshot date and may change as records are updated.
- The published aggregates should not be interpreted as a census of every golf or country club.
